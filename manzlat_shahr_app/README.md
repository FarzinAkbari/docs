# منزلت شهر (Manzlat Shahr)

اپلیکیشن آفلاین نمونه با UI نزدیک به «بانک شهر» برای **اندروید** و **ویندوز**.

## امکانات فعلی (نسخه اولیه)
- ورود با دو نقش: **کارمند** / **مدیر**
- تفاوت نقش‌ها: **مدیر** می‌تواند **کارمند اضافه کند**
- بعد از ورود: انتخاب ۳ نوع وام
- هر وام: فرم **۴ مرحله‌ای** (Wizard)
- پایان: **رسید پیش‌ثبت‌نام** + دکمه **چاپ / خروجی PDF**

## اجرا
نیازمند Flutter (SDK).

```bash
cd manzlat_shahr_app
flutter pub get
flutter run
```

## حساب‌های پیش‌فرض
- مدیر: `admin` / `1234`
- کارمند: باید از داخل پنل مدیر اضافه شود (نام کاربری + پین)

> نکته: همه چیز آفلاین است و داده‌ها فعلاً داخل حافظه محلی (Hive) ذخیره می‌شود.
